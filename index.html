2. Aturan Keamanan Firestore (Firestore Rules)

Pastikan Authentication (Google & Email/Password) dan Cloud Firestore aktif di Firebase Console. Tempel aturan berikut pada tab Firestore Database → Rules agar setiap pengguna hanya dapat mengakses datanya sendiri: 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}

Tips GitHub Pages: Tambahkan domain username.github.io Anda di Firebase Console → Authentication → Settings → Authorized domains agar Login Google berjalan lancar.
